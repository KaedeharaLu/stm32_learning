# 按键切换 LED 闪烁周期

将 GPIO、外部中断、软件消抖和定时器结合起来，完成一个可以上板运行的工程。

## 1. 功能要求

1. 上电后，LED 默认以 **1 秒** 为周期闪烁。
2. 每次有效按下按键，LED 的闪烁周期按照 **1 秒 → 2 秒 → 500 毫秒 → 1 秒** 的顺序循环切换。
3. 按键使用 **EXTI 外部中断**检测，并实现软件消抖：一次正常按下只切换一档，持续按住不连续切换，松开后再 次按下能够继续切换。
4. LED 闪烁使用 **TIM 定时器**实现，不能通过 `HAL_Delay()` 或空循环延时控制闪烁节奏。
**周期定义**：一次完整的“亮 + 灭”为一个闪烁周期，亮、灭各占一半。

| 闪烁周期 | 亮的时间 | 灭的时间 |
| :--- | :--- | :--- |
| 500 ms | 250 ms | 250 ms |
| 1 s | 500 ms | 500 ms |
| 2 s | 1 s | 1 s |

## 2. 实现提示

* 先分别验证 GPIO、按键中断、定时器，再把功能整合起来。
* 可以让定时器产生固定周期的中断，再通过软件计数实现不同的 LED 闪烁周期；具体方案自行设计。
* 消抖需要考虑按下和松开过程。
* 调试时可以查看当前档位、按键事件或计数变量。

# 任务分析

## 定时器

250ms、500ms、1s（1000ms）都是250ms的整数倍，可以以250为基准，利用另一个变量来计数等待几个250ms。

T=250ms，f=4Hz=$\frac{72×10^6}{1800×10000}$

```c
int period_num=2; //period_num * 250ms为周期，初始0.5s改变状态
int current_period=0;

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  if(GPIO_Pin==GPIO_PIN_9){
    period_num++;
    current_period=0;
    if(period_num>3){
      period_num=1;
    }
  }
}

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if(htim->Instance==TIM4){
    if(period_num==current_period){
      HAL_GPIO_TogglePin(GPIOC,GPIO_PIN_13);
      current_period=0; //复位计数器
    }
    current_period++;
  }
}
```

## 按键的软件消抖

消抖采取计数消抖法，每1ms扫描一次状态（上拉输入，默认是高电平），超过20ms状态保持不变认为状态稳定。

f=1kHz=$\frac{72×10^6}{72×1000}$

将前面写的更改周期的内容封装为一个函数，在计数消抖的函数中调用。

```c
int count=0; //计数器
int last_status=1; //原本状态
int now_status=1; //当前状态

void button_scan()
{
  now_status=HAL_GPIO_ReadPin(GPIOB,GPIO_PIN_9);
  if(now_status!=last_status){ //状态改变
    count++;
    if(count>=STABLE_COUNTER){ //达到稳定阈值
      count=0; //复位计数器
      //按键状态改变
      if(last_status==1){ //按下
        change_period();
      }
      last_status=!last_status;
    }
  }else{
    count=0; //出现了抖动，清空计数器
  }
}
```
